# UV Inspector — 低模 UV 本地检查工具

React + TypeScript + Three.js 实现的**纯本地** UV 检查工具：左右联动的 3D 模型视图与
2D UV 视图，棋盘纹理可视化拉伸，面积/角度畸变分别量化，翻转/重叠/接缝/非流形边检测，
xatlas WASM 可选自动展开，IndexedDB 工程存取。**无后端、无 CDN 运行时依赖**。

## 启动

```bash
npm install
npm run dev        # 开发
npm run build      # 类型检查 + 产物构建
npm run preview    # 预览构建产物
npm test           # 分析/身份保留相关的 Node 冒烟测试
```

## 身份模型（关键设计）

OBJ 有两个相互独立的索引空间，本工具严格保留：

- **位置顶点身份**：每个 OBJ `v` 一个稳定 id（数组下标）。同一个坐标写两次就是两个
  不同身份——**绝不按空间位置焊接**。
- **UV 顶点身份**：每个 OBJ `vt` 一个稳定 id。接缝两侧是不同的 `vt`（坐标可以相同
  也可以不同），因此接缝天然被表达，不需要在渲染时临时分裂顶点。
- **面身份**：每个 OBJ `f` 行一个 `sourceFace`；多边形扇面三角化产生的多个三角形
  共享该身份，分析/选择以三角面 id 为准。
- 每个三角形角点同时持有 `位置id` 与 `UV id`，与 `f v/vt` 双重索引一致。

渲染层使用**非索引逐三角几何体**，射线拾取 `face.a/3` 即稳定面 id；接缝两侧本来就是
不同角点，也不会被 Three.js 或 GPU 端合并。

### xatlas 的对接

xatlas **不按坐标焊接**输入顶点——它依据索引共享关系建立邻接。因此喂入的是按稳定
位置 id 索引的几何体（OBJ 里重复 `v` 即便同坐标也保留为不同输入顶点），输出通过
`oldIndexes` 映射回稳定 id。xatlas 在接缝处复制顶点，输出的每个新顶点获得独立 UV
身份；位置数组直接复用输入，面身份顺序不变。

## 检测口径

- **翻转**：以**"从面外侧观察"**为绕序契约——从面外侧看，几何面与 UV 绕序一致即正常，
  相反即镜像翻转。判据比较两个相互独立的符号：①几何朝向符号 `screen`，把 3D 三角形
  投影到垂直于外向法线的屏幕平面（屏幕轴取右手对：±z→(x,y)、±x→(y,z)、±y→(z,x)），
  其有符号面积的符号本身携带外向朝向（法线指向主轴 + 为正、− 为负）；②UV 朝向符号
  `detUv = 2·有符号UV面积`。两者同号为正常、异号为翻转。
  因此法线朝 **−X/−Y/−Z 的正常面允许 UV 有符号面积为负**（"负面积正常绕序"），不会误报。
  不能用 `detUv < 0` 直接判翻转（那等于强求所有面 UV 面积都为正）；也不能把同一对边
  向量导出的投影符号与法线分量相乘（那得到恒正的平方项 `nAxis²`）。
- **面积畸变**：`(|UV面积| / 3D面积) / 全网格中位密度`，1 为均匀；面板同时给出
  `|log2|` 与拉伸倍率。
- **角度畸变**：3D 与 UV 三角形三个对应内角的最大偏差（度），另有 RMS 参与整体统计。
- **接缝边**：恰有两个面共享的位置边，但两侧的 UV 顶点身份不一致；同时区分
  "身份切开但坐标相同"的假缝。
- **非流形边**：关联面数不是 1（边界）或 2。
- **UV 岛**：按 UV 顶点身份并查集；`mirrored` = 岛内多数面未通过朝向检查。
- **重叠**：先包围盒筛，再 6 轴 SAT + Sutherland–Hodgman 裁剪确认正面积交集；
  同岛共享 UV 顶点的相邻面不算重叠，边接触（零面积）不算重叠。
- **退化**：3D 面积≈0 或 UV 面积≈0 分别标记，不参与面积比率、角度、翻转与重叠统计。

工具栏的「修正翻转岛」对每个镜像岛沿自身 U 中线镜像，仅改坐标、不动身份。

## 样例

工具栏「载入样例」：

1. **镜像岛 / 接缝** — 折页双面片：一个正常岛 + 一个镜像岛，共享位置边是接缝。
2. **立方体接缝网** — 8 位置顶点 / 6 UV 岛 / 12 接缝，绕序正确、无翻转重叠。
3. **非流形 / T 接头 / 退化** — 三面共享一边、未焊接的 T 型接头、UV 塌缩退化面。
4. **UV 重叠 / 拉伸** — 两面片映射到同一 UV 方块，其一 U 向压缩。

## 操作

- 2D UV：左键选面、Shift 加选，右键/Shift+拖拽平移，滚轮以光标为中心缩放。

## 可审计的 UV 修订图谱

每次改变 UV 的操作——**镜像所选岛、修正翻转岛、xatlas 成功展开、导入 OBJ、从历史恢复**——
都会在版本树上追加一个**不可变**节点，记录父版本、操作类型与摘要、完整网格、分析摘要。

- **原子一致**：节点创建是同步的，图/head/mesh/分析/选择/dirty 在同一次状态提交中切换；
  之后才异步去抖保存（400ms）。异步保存失败只标记"保存失败"，内存图谱完整保留，下次整图重放。
- **去重**：结果与父版本 UV 逐位等价（重复点"修正"、空选择镜像等）不产生节点。
  "从祖先恢复"例外——即使 UV 与目标相同也建 `restore` 节点，以记录 head 跳转与分支点。
- **分支**：从任意历史节点恢复会以该节点为父创建 restore 子节点，原分支与所有祖先保持不变、仍可达。
- **半写入/冲突安全**：整棵图是 IndexedDB 中的**单个文档**，一次 readwrite 事务只做一次 put；
  事务 abort（写冲突/配额/刷新中断）整体回滚，不会出现半个新节点或 head 错指。
- **GC**：只允许删除从任何根都不可达的孤儿草稿节点；仍可达的版本拒绝删除。
- **预览/比较**：点击历史行只预览（不移动 head，视图与导出对应预览版本）；选 A/B 两版本
  比较翻转面、岛、接缝、重叠、退化、畸变差异及翻转面 id 的增减。
- **刷新恢复**：最近工程 id 记在 localStorage，重开页面自动恢复最后一致状态。
- **OBJ 导出严格对应当前选定版本**（预览时为预览版本，文件名含 `v<seq>`）。

### IndexedDB schema 与迁移

v2：`projects` 中每条记录为 `{ id, name, updatedAt, version:2, graph }`，`graph` 即整棵版本树
（含命名分支、合并提交、未完成合并草稿、乐观并发 etag）。
旧版（v1，仅存当前 mesh）在 `onupgradeneeded` 同一事务中读出并迁移为单根版本图谱；
另有防御性迁移路径兜底。迁移根版本上的镜像岛/负轴翻转判定/xatlas 修正/OBJ 往返结果不变。

## 提案分支与三方合并

模型师可从任意历史版本创建**提案分支**，在其中镜像岛、修正翻转或 xatlas 展开（提交只落在该分支），
然后把提案相对**共同祖先**的 UV 改动合并回目标分支（默认 main），而不是恢复整份 mesh。

- **三方差异**（`model/branches.ts`）：base = mergeBase(proposal, target)，按稳定 **face id + 角点 UV 身份**
  比较每个面。仅一方相对 base 改动 → 自动合并；双方都改且结果一致 → 自动取任一；
  同一面双方给出不同结果（`same-face-changed`），或坐标级编辑共享同一被双方改动的 UV 顶点
  （`shared-uv-vertex`）→ 冲突。
- **坐标级 vs 拓扑级**：镜像/修正是坐标级（UV 数组长度与角点 UV id 不变），直接把提案坐标写入相同 id；
  xatlas 是拓扑级（重建 UV 数组/引用），输出追加为新 UV 顶点再重映射。
- **冲突决议可审计**：每个冲突保留祖先/提案/目标三方快照与原因，可逐项选「采用提案 / 采用目标 /
  手动 UV」；决议写入 `MergeDraft`，未全部决议禁止发布。
- **合并提交是双亲节点**：第一父=目标头、第二父=提案头，附 `MergeCommitInfo`（祖先、双亲、逐冲突决议、
  自动面/冲突计数）。提案分支标记 merged，但所有节点与分支指针都保留、仍可达。
- **合并草稿可续可弃**：`graph.pendingMerge` 随图持久化，刷新/写失败后重开工程仍能继续决议或丢弃；
  草稿引用的版本被视为可达，不会被 GC 误删。
- **并发安全**：整图单文档 + etag 乐观锁（`saveProjectGraphIfEtag`）。双标签页交错保存时，过期 etag
  抛 `ConcurrentWriteError` 并回传远端，调用方用 `mergeGraphs` 并入远端的不可变节点/分支后重试，
  任一可达分支都不被覆盖。
- **OBJ 导出**严格对应当前 checkout 的 head；合并发布后 head 即双亲合并提交，文件名含 `v<seq>`。

工具栏「提案 / 合并」打开对话框：创建并切换提案分支、选择提案/目标、计算三方差异、逐项决议、
预览合并摘要、不可逆发布前二次确认。
